# LocalPass 界面规范（ui-redo-d · Bitwarden 原生布局）

> 更新：2026-11-27　｜　权威原型：`design-system/legacy/prototypes/ui-redo-d/index.html`
> 逐屏落点与完成度见 [LocalPass-屏对照表.md](./LocalPass-屏对照表.md)；
> 人工验证步骤见 [LocalPass-验证清单.md](./LocalPass-验证清单.md)。
>
> 旧「方向 C」原型（`design-system/legacy/prototypes/ui-redo-c/`）已归档，不再是落地依据。
> 新页面若与本文冲突，先改本文与原型，再改代码。

## 1. 范围与基准

| 端                 | 设计基准                         | 形态                               |
| ------------------ | -------------------------------- | ---------------------------------- |
| Chrome 扩展弹窗    | 380 × 620（Chrome 按内容自适应） | 单列；头部 / 内容 / 底部导航       |
| 桌面端（Electron） | 1160 × 760（最小 980 × 640）     | 深蓝左 rail + 列表 + 右栏详情/抽屉 |
| 网页内联菜单       | 锚定在页面字段上                 | 账户优先的浮层，不进入扩展弹窗     |

三端共用同一套 Bitwarden 语义令牌与组件，不做第二套视觉语言。
差异只在容器宽度与平台能力，不在配色、行高、按钮层级。

## 2. 设计令牌

- **唯一来源**：`libs/components/src/tw-theme.css`（亮/暗双主题）。
  原型 `ui-redo-d/style.css` 是它的镜像，只用于演示，不进产品构建。
- 主色 `#175ddc`（`brand-700`）；桌面左 rail 用 `brand-950`（`#162455`）；
  危险色 `red-700`；成功色 `green-700`；正文 `gray-900`，说明文字 `gray-600/500`。
- 深色主题由 `.theme-dark` 切换，品牌色提亮为 `#6baefa`；不要写死只在亮色下成立的颜色。
- 新代码直接使用语义类：`tw-bg-background`、`tw-bg-background-alt`、`tw-text-main`、
  `tw-text-muted`、`tw-border-border-light`、`tw-text-fg-brand`、`tw-text-fg-danger`。
- `libs/angular/src/local-ui/local-ui.scss` 里的 `--lp-*` 只是旧组件兼容别名，
  指向同一批语义令牌；新组件不应再新增 `lp-*` 变量。

## 3. 组件规则

1. **复用优先**：先找 `libs/components/` 与 `libs/angular/src/local-ui/` 的现有组件
   （`bit-dialog`、`bit-button`、`bit-form-field`、`lp-row`、`lp-group`、`lp-empty`、
   `lp-page-header`、`lp-toast`），不为单个页面造平行原语。
2. **分组列表是基本容器**：标题 + 卡片 + 行；同一组行之间一条分隔线，最后一行无。
   行右端最多一个收尾元素：值 / 开关 / chevron / 复制图标。
3. **按钮**：主按钮实心 `brand`，次按钮白底描边，危险按钮红字红边并放页尾；
   同一屏只允许一个主操作。按钮文字用动词，不用「确定/是」。
4. **状态提示就地显示**：行下方或段落里，不用全局横幅；黄色提醒，红色失败，
   失败文案必须给出一个可执行出口（改配置 / 重试 / 从备份恢复）。
5. **空状态**：图标 + 一句目的说明 + 一个主按钮 + 最多两个次按钮（`lp-empty`）。
6. **危险操作**：删除、清空回收站、断开存储、销毁本机数据一律二次确认；
   确认文案写清后果，不使用实心红色大按钮。
7. **动效**：120–200ms，`prefers-reduced-motion` 下关闭；不做装饰性动画。

## 4. 条目类型（8 类）

存储层只使用原生 `CipherType`；8 类中的令牌 / 许可证 / 服务器借 `Login` 承载，
用自定义字段 `lp:kind` 标记。映射的唯一实现是 `libs/local-vault/src/items/item-kind.ts`。

| 界面类型 | 存储类型     | 关键字段（其余进附加项）                             | 图标 |
| -------- | ------------ | ---------------------------------------------------- | ---- |
| 登录     | `Login`      | 用户名、密码（+生成）、验证码密钥、网址列表、Passkey | 🔐   |
| 令牌     | `Login`      | 服务、令牌（隐藏）、权限范围、有效期、环境           | 🔑   |
| SSH 私钥 | `SshKey`     | 私钥（隐藏）、公钥指纹、口令、用于（哪几台主机）     | 🗝️   |
| 许可证   | `Login`      | 软件、序列号（隐藏/复制）、席位/版本、购买日期       | 📜   |
| 卡片     | `Card`       | 持卡人、卡号（隐藏/复制）、有效期 + 安全码、类型     | 💳   |
| 身份     | `Identity`   | 证件类型、姓名、证件号（隐藏）、有效期               | 🪪   |
| 服务器   | `Login`      | 主机:端口、协议、用户名、认证方式、sudo 备注         | 🖥️   |
| 笔记     | `SecureNote` | 标题 + 多行内容                                      | 📝   |

规则：

1. **8 类是上限**。新增类型先证明现有类型装不下；加类型只改字段与展示，不改加密与状态键。
2. **类型选择是独立一步**：列表「＋」→ 类型网格 → 对应表单；表单顶部类型胶囊可原地切换。
3. **跨类型引用**：服务器的「认证方式」可引用某个 SSH 私钥条目，不复制私钥内容两份。
4. **借用密码槽的类型**（令牌 / 许可证 / 服务器）必须排除在密码历史之外，
   由 `isSecretCarrier()` 判断；新增借用类型时同步登记。
5. **导入回退**：没有 `lp:kind` 的条目按原生类型猜类别（`defaultKindOf`），
   不因为缺少标记而丢字段。

## 5. 平台能力矩阵

| 能力                         | 扩展（Chrome）      | 桌面端 macOS        | 桌面端 Windows/Linux |
| ---------------------------- | ------------------- | ------------------- | -------------------- |
| 安全密码解锁                 | ✓                   | ✓                   | ✓                    |
| PIN 解锁                     | ✓                   | ✓                   | ✓                    |
| Touch ID 解锁                | —（无生物识别接口） | ✓ 仅「设置 → 安全」 | —                    |
| 安全密钥解锁（WebAuthn PRF） | ✓                   | 未实现（本轮不做）  | 未实现               |
| 页面内联填充菜单             | ✓                   | —                   | —                    |
| 原生消息（解锁代理）         | ✓                   | ✓                   | ✓                    |
| 网络闸门                     | ✓                   | ✓                   | ✓                    |

规则：

- **Touch ID 只在 macOS 桌面端**，入口只在「设置 → 安全」；首次向导与扩展弹窗里不出现。
  渲染条件：`process.platform === "darwin"` 且系统 `canPromptTouchID()` 为真。
- 扩展侧不得出现「用指纹解锁」字样或图标。
- PRF 凭据与选项只保存在登记它的扩展本机，不随 `account.json` 同步；换设备需重新登记，
  桌面端显示「不可用」。

## 7. 关键流程

1. **首次**：设置安全密码（邮箱只作本机派生密钥）→ 建库 → 空状态引导新建 / 导入 /
   从备份恢复。全程没有注册、登录、账号字样。
2. **日常**：解锁 → 列表 → 详情（复制、看 OTP、二维码）→ 编辑 / 删除。
3. **导入**：选择来源 → 预览（统计、前 5 条、检查项）→ 确认后写入；取消不写入。
4. **同步 / 导出（全部手动）**：设置 → 云备份 → 「同步」推送并拉取密文快照，
   「导出备份」写标准加密 JSON。**没有任何定时器，本地写入不触发上传。**
5. **恢复**：填存储配置 + 安全密码 → 读桶根 `account.json` → 校验账号归属 → 拉快照 →
   预览覆盖范围 → 写入。失败不破坏本机现有数据。
6. **冲突**：同步发现两边都改过 → 停在冲突列表，由用户选择保留本机 / 远端 / 两份。
7. **增删改查**：
   - 增：列表「＋」→ 类型 → 名称/文件夹/收藏 → 凭据 → 自动填充网址 → Passkey →
     自定义字段 → 附加项（备注/密码重提示/附件）。
   - 读：详情分区顺序：凭据 → Passkey → 自动填充网址 → 自定义字段 → 附加项 → 时间戳。
   - 改：详情「编辑」→ 同一套表单；弹窗整页替换，桌面右栏抽屉。
   - 删：详情「删除」→ 确认 → **软删除进回收站**；回收站默认保留 30 天，
     清空回收站必须二次确认，并提示云备份里可能还有旧快照。

## 8. 复制、键盘与反馈

- **详情里的值行整行可点复制**（`lp-row`）；顶部关键动作保留图标按钮
  （复制用户名 / 复制密码 / 打开网站）。多行字段（公钥、备注）只允许点尾部复制按钮。
- 复制反馈三件套：行底变绿、行尾图标从复制变 ✓（约 1.3 秒）、底部浮层
  「<字段> 已复制」（约 1.7 秒）。剪贴板写失败也照常给反馈，不让用户以为没点到。
- 隐藏字段复制真实值，界面上仍显示掩码；不把明文写进日志、错误或持久化状态。
- 键盘：
  - 桌面端：`⌘N` 新建、`⌘K` 聚焦搜索、`↑↓` 选择、`↵` 打开、`esc` 返回/关闭抽屉。
  - 扩展弹窗：页面内 `Enter` / `Space` 触发可复制行与按钮；全局快捷键由
    `manifest.v3.json` 的 `commands` 提供（打开弹窗、自动填充、生成密码、锁定），
    不假设弹窗内支持 `⌘K`。
  - 网页内联菜单：`↑↓` 选择、`↵` 填充、`esc` 关闭。快捷键提示写在按钮或提示条上。
- 焦点：所有可点元素有 `:focus-visible` 环；可复制行 `role="button"` 且可用
  `Enter` / `Space` 触发。

## 9. 文案规则

- 不出现「注册 / 登录 / 账号 / 厂商服务器」；用「保险库」「安全密码」「本机」。
  条目类型「服务器」是产品字段名，属于例外。
- 「同步」指快照镜像，「导出」指带备份口令的标准 JSON；不要把两者都叫「备份」。
  界面里的「云备份」是设置页名称，页内动作必须分别写「同步」「导出备份」。
- 说明文字写后果，不写营销：「忘了就打不开——记得做备份」「失败不会改动本地数据」。
- 错误提示给出口：改配置 / 稍后重试 / 从备份恢复。
- 中文文案以 `apps/browser/src/_locales/zh_CN/messages.json` 为准；
  只改 `en` 的键由 Crowdin 流程处理，不在本仓库手工补其他语言。

## 10. Tailwind 与主题

- 类名一律带 `tw-` 前缀；缺前缀的类会被忽略，样式静默失效。
- **禁止任意值**（`tw-[12px]`、`tw-text-[#ff0000]`）；颜色只用语义令牌。
  需要新色时先加主题变量，再在 Tailwind 配置里暴露。
- 不写自定义类名（如 `lp-row__label`）到模板；要复用就做成组件。
- 主题变量以 `libs/components/tailwind.config.base.js` 为准；新增令牌必须同时覆盖亮/暗两套。
