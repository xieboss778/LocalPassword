## 3. 组件与展示规则（含 AGY 细化定稿）

1. **复用优先**：Angular 客户端优先复用 `libs/components/` 与 `libs/angular/src/local-ui/` 组件，不按单屏造平行原语。
2. **列表视图纯净聚焦（禁止 2FA 验证码噪音）**：
   - **桌面端第二栏列表、Quick Access 搜索列表、浏览器扩展列表均不显示 2FA / Google 6 位动态验证码**，仅展示条目名称、核心副标题（用户名/服务名/尾号等）与条目类型徽标。
   - **TOTP 只在条目详情页展示**：展示实时 6 位动态口令、30 秒倒计时环与复制操作。
3. **桌面端登录详情不直接显示 Google 动态验证器绑定二维码**：
   - **桌面端详情页不渲染「Google 动态验证器绑定二维码」卡片与内联展开切换**（保持详情第一屏字段聚焦；顶部工具栏可保留按需打开二维码抽屉图标）。
   - **浏览器扩展保留独立二维码页（`ext-totp-qr`）**，通过本机 Canvas / `qrious` 离线绘制，绝不向外部图片或二维码接口发起请求。
4. **详情页不保留冗余「复制主要值」按钮**：
   - 桌面端详情头部精简为「收藏星标 + `编辑 ⌘E`」；扩展详情底部动作栏精简为「填充到当前网页（或编辑字段）+ 更多动作单」。每行字段本身点击即复制，无需额外的「复制主要值」按钮。
5. **复制反馈三件套与隐私遮蔽**：
   - 单行字段整行可点复制，反馈为：**行底变绿 + `已复制 · <secs>s` / ✓ + 底部按全局「清空剪贴板」延迟显示的自动清空倒计时（附「立即清空」；「永不清空」不显示自动清空）**。
   - 敏感字段默认掩码显示，明文切换 `30 秒` 后自动收回；多行文本（SSH 公私钥、笔记正文、地址）点右侧复制按钮，避免选中文本时误触发复制。
6. **网络闸门（Default Deny）**：
   - 默认拒绝全部未授权出站请求，**锁库状态恒为 0 次网络请求**，**不拉取远程网站图标**（统一本机首字母色标 SVG 头像）。
   - 网络闸门页面**只展示用户授权白名单**（自选 R2/S3 存储域名）；泄露检查（HIBP）**标注「未实现」**，没有开关，也不提供手动的 5 位哈希前缀查询；其余为默认拒绝守则；**严禁在前端/原型写死虚假的遗留拦截域名清单**（如 `sentry.io`、`icons.local.invalid`、`api.local.invalid`）。
7. **空态、危险操作与图标规范**：
   - 空态（`mac-empty`、`ext-empty`、`web-no-match`、`web-inline-empty`）不画装饰插画，明确给出可执行出口（新建 / 导入 / 从 R2 恢复 / 清除筛选 / 生成密码）。
   - 删除默认优先**软删除移入回收站（30 天，支持 5 秒 Toast 撤销）**；清空回收站、断开存储、销毁本机数据必须有醒目后果说明并二次确认。
   - **严禁使用 Emoji 作为功能图标**，统一使用 `1.5px` 描边几何 SVG 图标与系统等宽数字 `font-variant-numeric: tabular-nums`。
8. **同步只有手动触发**：同步 / 导出只由用户显式点击触发，产品不注册定时器、不做 30 秒去抖，也不在解锁或窗口聚焦时自动同步；AGY 原型的自动同步屏与开关是**原型概念、未实施**。
9. **扩展语言跟随浏览器**：扩展外观页的语言行只读说明「跟随浏览器语言」，显示的不是可切换的当前语言项，也不持久化语言偏好；桌面端外观页的语言切换（中/英）是独立设置，两者不要混为一谈。
10. **桌面与扩展的新建/编辑入口不同**：桌面端统一在 AGY 保险库抽屉内打开（新建 `/vault?action=add&kind=...`、编辑 `/vault?cipherId=...&edit=1`；旧 `/new-item-v2`、`/edit-item-v2` 重定向到 `/vault`），扩展保留整页新建/编辑表单；两端表单交互细则一致。
11. **密码 / 版本历史保留 10 个旧版本**：每次保存前把上一版密文快照写入本机加密状态，最多保留 10 个旧版本（当前版本另计）；恢复旧版本会写回该版本，并把原当前版本推入历史。
12. **数据与安全使用跨平台真实信息**：文件保护显示「系统保护」（OS-protected），官方服务器副本恒为 0，云备份未配置时显示「—」；目录行说明路径由操作系统管理、随平台变化，不写死 `0600` 权限位或 macOS `~/Library/Application Support/...` 路径。

## 4. 条目类型（8 类）与动态定制表单规则

存储层沿用原生 `CipherType` + 自定义字段 `lp:kind`（映射权威实现：`libs/local-vault/src/items/item-kind.ts` 与 `item-fields.ts`）。8 类是上限，**每类字段结构互不混用**：

| 类型 (`ItemKind`)        | 存储承载     | 默认字段（各自定制，支持删除与召回）                                                                       | 扩展/可选字段                                     | 交互特性                                                                           |
| ------------------------ | ------------ | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **登录 (`login`)**       | `Login`      | 用户名、安全密码（含生成）、动态口令密钥、主网址                                                           | 备用网址、备注                                    | 参与网页登录与 2FA 自动填充；支持 Passkey                                          |
| **令牌 (`token`)**       | `Login`      | 所属服务、Key ID、API 令牌（隐/生成）、权限范围                                                            | 过期日期、运行环境（下拉+自定义）、管理 2FA、备注 | 借用密钥槽，排除在密码历史之外（`isSecretCarrier()`）                              |
| **SSH 私钥 (`ssh-key`)** | `SshKey`     | 算法与位数（下拉+自定义）、公钥指纹、公钥正文、私钥正文（隐/多行）                                         | 保护口令、适用主机、备注                          | 可被 `server` 条目跨条目引用，不复制私钥两份                                       |
| **许可证 (`license`)**   | `Login`      | 软件名称、授权档位（下拉+自定义）、序列号（隐）、授权邮箱                                                  | 席位设备数、购买日期、到期日期、订单编号、备注    | 离线序列号归档                                                                     |
| **卡片 (`card`)**        | `Card`       | 持卡人姓名、发卡行/组织（下拉+自定义）、银行卡号（隐）、**有效期（`MM/YY` 如 `02/32`）**、安全码 CVV（隐） | 交易 PIN、账单邮编、备注                          | **有效期使用单个 `MM/YY` 自动斜杠输入框（禁止拆成月/年两个下拉框）**；参与结账内联 |
| **身份 (`identity`)**    | `Identity`   | 姓、名、证件类型（下拉+自定义）、证件号（隐）、手机号、电子邮箱                                            | 详细地址、邮政编码、公司名称、备注                | 参与地址与实名表单内联                                                             |
| **服务器 (`server`)**    | `Login`      | 主机地址、端口、连接协议（下拉+自定义）、登录账号、登录口令、关联 SSH 密钥（下拉）                         | 特权/sudo 备注、区域/机房、备注                   | 关联库内已有 SSH 私钥条目                                                          |
| **笔记 (`note`)**        | `SecureNote` | 笔记分类（下拉+自定义）、加密正文（多行）                                                                  | 介质存放提示                                      | 纯加密文本，无多余用户名/网址字段                                                  |

表单交互细则（桌面抽屉与扩展表单一致，均属 AGY 表单规范；桌面端在保险库抽屉内打开，扩展保留整页表单）：

1. **默认字段与自定义字段双端支持实时增删**：
   - 每行默认字段右侧提供 `×` 移除按钮；移除后的默认字段或未选用的可选字段收拢在下方「+ 添加默认字段」胶囊区，可随时点击加回。
   - 「自定义字段」支持自由添加、填写键/值、独立切换隐私掩码（🔒/👁）与删除，并参与全字段搜索。
2. **枚举下拉与自定义降级**：
   - 有限枚举集合的字段（**发卡行/组织、运行环境、算法与位数、授权档位、证件类型、连接协议、关联 SSH 密钥、笔记分类、文件夹归属**）使用 `<select>` 下拉框选择；选择「自定义其他…」即原地切为自由文本输入框，旁边提供 `预设 ▾` 按钮随时切回下拉菜单。
   - 当加载的已有条目字段不在预设集合内时，表单自动以自定义输入框展开并回显原值。
3. **卡片有效期例外**：银行卡**有效期必须使用单个 `MM/YY` 文本框**（如 `02/32`，输入前 2 位数字自动补 `/` 并支持无阻退格），绝不退化为「过期月份 / 过期年份」两个独立下拉框。

## 7. 键盘、快捷键与设置映射规范

- **取消系统全局热键监听**：Quick Access 快捷搜索浮窗改为**应用内 `⌘K / /`**，设置页「键盘映射」明确标注「仅本应用内生效 · 已取消系统全局热键监听 · 无全局后台监听」（扩展弹窗系统级快捷键仍遵循 Chrome MV3 `manifest.v3.json` `commands` 机制）。
- **默认应用内键位映射（可逐项删除与重置默认）**：
  - `⌘K / /`：应用内快速检索（覆盖全字段 + `=favorite` / `=totp` / `=ssh` 语法）
  - `↑↓ · ↵`：列表/内联行移动与打开详情/确认填充
  - `⌘C / ⇧⌘C`：复制用户名 / 安全密码（按全局「清空剪贴板」延迟自动清空）
  - `⌘N · ⌘E`：新建 / 编辑当前条目
  - `Delete / ⌘⌫`：软删除移入回收站（支持撤销）
  - `⌘L`：立即锁库并广播至扩展与网页端
- 设置中心「键盘映射」支持单行点击删除键位解绑与「重置默认」恢复；所有可交互元素必须有 `:focus-visible` 焦点环。

## 8. 网页内联联动规则（对应 content-script 生命周期）

网页内联菜单与右上角通知条必须覆盖真实浏览流程的完整闭环：

1. **区别「0 凭据新站」与「过滤无结果」**：首次访问库内没有任何条目的新域名时显示 `web-no-match`（引导在此站点新建 / 生成密码 / 从他站借用）；已有条目但搜索/输入过滤无匹配时显示 `web-inline-empty` 并提示全站总数与一键清除筛选。
2. **保存流程分层**：首次登录新站点弹出 `web-save-new`（支持 `<select>` 选归属文件夹与「从不提示此站」）；已有同名账号改密弹出 `web-save-bar`（「更新条目」而非盲目新建）；同域多账号无法消歧时弹出 `web-multi-save`——选择器只列同域且已保存密码等于本次提交当前密码的条目（用户名可以不同），仅用户名匹配而密码不等的条目不会出现；零匹配时仍显示选择器，只保留「Save as new entry #N」；保存成功后切入绿色确认态 `web-save-confirm`（给出「补充 2FA / 编辑条目」出口）。
3. **风控闭环**：检测到刚填入或登录的凭据属于体检检出的重复/弱密码时，触发右上角 `web-at-risk`（对应 `AtRiskPasswordNotification`）引导原地改密。
4. **防遮挡填充回执**：多字段自动填充完成后收起内联列表，仅在页面右下角展现轻量 `web-autofill-toast` 撤销卡。

## 9. 文案与 Tailwind 工程约束

- **术语统一（对齐 [GLOSSARY.md](../GLOSSARY.md)）**：不出现向远程厂商「注册 / 登录 / 云服务器」字样；统一用「保险库」「安全密码」「本机」「桶」「同步」「导出」「恢复」（条目的「服务器」类型与浏览器内「网站登录表单」语境除外）。
- **错误文案必须给出后果与出口**（如「改配置 / 稍后重试 / 从 R2 恢复」）。
- **Tailwind 约定**：Angular/HTML 模板中 Tailwind 工具类一律保留 `tw-` 前缀，禁止任意值（如 `tw-[12px]`、`tw-text-[#...]`），颜色走语义主题变量（`libs/components/tailwind.config.base.js`）。中文文案以 `apps/browser/src/_locales/zh_CN/messages.json` 为准，不同步维护其他语种翻译。
