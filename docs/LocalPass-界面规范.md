# LocalPass 界面规范（方向 C · 分组原生）

这份文档是界面重构的**定稿依据**，配套原型 `prototype/ui-redo-c/`（打开 `index.html`）。
落码时以本文为准；本文与原型冲突时，先改本文再改代码。

## 1. 范围

| 端                 | 尺寸                         | 界面数 |
| ------------------ | ---------------------------- | ------ |
| Chrome 扩展弹窗    | 380 × 620                    | 26     |
| 桌面端（Electron） | 1160 × 760（最小 980 × 640） | 10     |

两端共用同一套语言：**分组列表**是唯一容器。差异只在宽度——弹窗单列，桌面端「侧栏 + 列表 + 详情」三栏。

## 3. 组件规则

1. **行（row）**：左（可选 emoji/图标）+ 主文字（可带副文字）+ 右端三选一 —— 值、开关、chevron。右端最多两个元素。
2. **分组**：`gtitle`（10.5px 大写，间距 .07em）+ 卡片；分组之间 8px；同组行之间 1px 分隔线，最后一行无。
3. **按钮**：
   - 主：实心 `brand`，整宽，一句话动词（「解锁」「创建保险库」）
   - 次：白底 + 1px 实色边
   - 危险：白底 + 红字红边（**不用实心红**），且一律放页尾
   - 文字链：仅次要路径（「忘记密码，从备份恢复」）
4. **状态提示**：一律就地（行下方 / 段落里），不用全局横幅。黄色 = 提醒，红色 = 失败。
5. **空状态**：图标 + 一句目的说明 + 两个出口（新建 / 导入或恢复）。

## 3.5 条目类型（8 类，简约但覆盖真实使用）

| 类型 | 说明 | 关键字段（≤5，其余进附加选项） | 图标 |
| --- | --- | --- | --- |
| **登录** | 网站 / App 账号 | 用户名、密码（+生成）、验证码密钥、网址列表、Passkey | 🔐 |
| **令牌** | API Key、访问令牌（从原「密钥」拆出） | 服务、令牌（隐藏）、权限范围、有效期、环境 | 🔑 |
| **SSH 私钥** | 登录服务器用的私钥（从原「密钥」拆出） | 私钥（隐藏）、公钥指纹、口令、用于（哪几台主机） | 🗝️ |
| **许可证** | 软件序列号与激活码（从原「密钥」拆出） | 软件、序列号（复制）、席位/版本、购买日期 | 📜 |
| **卡片** | 银行卡 / 信用卡 | 持卡人、卡号（可扫描）、有效期+安全码、类型 | 💳 |
| **身份** | 个人资料 / 护照 / 驾照（先收在一个类型里，证件类型做下拉） | 证件类型、姓名、证件号（隐藏）、有效期 | 🪪 |
| **服务器** | 主机与远程登录凭据 | 主机:端口、协议、用户名、认证方式（可引用 SSH 私钥条目）、sudo 备注 | 🖥️ |
| **笔记** | 恢复码 / 配置片段 | 标题 + 多行内容 | 📝 |

规则：

1. **8 类是上限**。新增类型要先证明现有类型装不下，再在类型网格加一格（桌面 4×2、弹窗 2×4）。
2. **类型只改字段与展示，不改加密**——同一套 SDK 加密、同一套状态键。
3. **类型选择是独立一步**：列表「＋ 新建条目」→ 类型网格（8 格，每格图标 + 名称 + 一句用途）→ 对应表单。
4. **表单是右栏内联**（桌面）/ 整页（弹窗），顶部类型胶囊可原地切换，不丢失已填内容。
5. 列表行图标由类型决定，副标题写该类型的识别信息（登录→账号、服务器→主机:端口、令牌→范围/环境、SSH 私钥→指纹、卡片→尾号、笔记→行数）。
6. **跨类型引用**：服务器的「认证方式」可以选「私钥（来自某个 SSH 私钥条目）」，避免私钥内容复制两份。
7. 原「密钥」拆成 令牌 / SSH 私钥 / 许可证 三类，是因为这三者的**关键字段完全不同**（令牌讲权限与过期、私钥讲指纹与口令、许可证讲席位与购买），合在一个类型里只能靠下拉，用起来会慢。

| 原生消息（解锁代理）         | ✓                    | ✓                         | ✓                    |

规则：

- **生物识别在本轮只做 macOS**，且入口只出现在桌面端「设置 → 安全」；首次向导与弹窗里**不出现**。
- 扩展侧不得出现任何「用指纹解锁」字样或图标。
- 判断顺序：`process.platform === "darwin"` **且** `systemPreferences.canPromptTouchID()` 同时成立才渲染。

## 6. 关键流程

1. **首次**：设置安全密码 → 建库（空状态引导新建 / 导入 / 从备份恢复）。
2. **日常**：解锁 → 列表 → 条目详情（复制密码 / 看 OTP / 扫码）。
3. **导入**：Google Authenticator 导出截图或 `otpauth-migration://` → 预览（去重、跳过 HOTP）→ 导入。
4. **备份（手动）**：设置 → 云备份 → 立即同步 / 立即备份 / 存储配置。**任何本地写入都不触发上传。**
5. **恢复**：填存储配置 + 安全密码 → 验证 `account.json` → 拉快照 → 写入（最后一步，失败不破坏现有数据）。
6. **冲突**：同步发现两边都改过 → 停在不一致状态，让用户选「保留远端 / 保留本机 / 两边都留」。
7. **增删改查（两端一致，字段对齐上游 cipher-form / cipher-view）**
   - 增：列表头部「＋ 新建条目」→ 表单依次为 **类型 → 项目（名称/文件夹/收藏）→ 登录凭据（用户名/密码+生成/验证码密钥）→ 自动填充网址（可增删）→ Passkey → 自定义字段（文本/隐藏/布尔/链接，可增删）→ 附加选项（备注/密码重提示/附件）**
   - 读：列表 → 详情，分区顺序与上游一致：**凭据 → Passkey → 自动填充网址 → 自定义字段 → 附加项（备注/密码重提示/附件）→ 时间戳**
   - 改：详情 →「编辑」→ 同一套表单（桌面端右栏内联，弹窗整页替换），底部固定「保存/取消」，未保存有提示
   - 删：详情「删除」→ 确认（桌面端模态 / 弹窗底部操作单，含 克隆 / 收藏 / 移到回收站）→ **软删除进回收站**
   - 回收站：30 天保留，每条可「恢复 / 永久删除」，顶部「恢复全部 / 清空回收站」；清空才不可逆

**删除的三条硬规则**：删除只影响本地（云端快照要等手动同步才变）；软删除默认 30 天；清空回收站必须二次确认且文案写「云备份里可能还有旧快照」。

## 7. 文案规则

- 不出现「注册 / 登录 / 账号 / 服务器」——用「保险库」「安全密码」「本机」。
- 说明文字写**后果**，不写营销：「忘了就打不开——记得做备份」「失败不会改动本地数据」。
- 错误提示给**出口**：改配置 / 稍后再试 / 从备份恢复。

## 8. 实现顺序（落码时按这个来）

1. 设计令牌落进 `tailwind.config.js` + `libs/components` 已有变量（不新增设计系统）。
2. 解锁页 + 列表页 + 详情页（弹窗），复用 `libs/angular` 的现有组件壳。
3. `libs/auth` 里 20 个零 OnPush 组件跑 `angular-modernization` 的 schematic（standalone → `@if` → signals → inject）。
4. 桌面端安全设置页 + Touch ID 接线（原生 `OsBiometricsServiceMac` 已存在）。
5. 备份 / 恢复 / 冲突三屏，接 `VaultBackupSyncService` 现有接口。
6. 内联填充菜单（content script）单独一票。
