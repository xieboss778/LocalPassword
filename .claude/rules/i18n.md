# Localization

User-visible strings (templates, toasts, dialogs, ARIA labels, validation messages) must be localized via `I18nPipe` in templates or `I18nService.t()` in TypeScript.

When adding or renaming a key, update **both `en` and `zh_CN`** in each app that uses it.
For a shared-library string, update every consuming app:

- Browser: `apps/browser/src/_locales/{en,zh_CN}/messages.json`
- Desktop: `apps/desktop/src/locales/{en,zh_CN}/messages.json`

Edit the source files, not the generated `apps/desktop/build/locales/` copies.
