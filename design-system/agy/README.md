# LocalPass · AGY 紧凑全端联动原型（v4）

> **状态：73 个原型屏** — 1 个联动沙盒（`link-sandbox`，仅演示）+ 29 个 Mac 桌面屏 + 29 个 Chrome 扩展屏 + 14 个网页内联屏。
> 其中 72 个产品屏在 [docs/LocalPass-屏对照表.md](../../docs/LocalPass-屏对照表.md) 中有对应产品代码；`link-sandbox` 不对应任何产品界面。
> 本目录是产品 UI/UX 规范与可交互原型，不接入 `apps/` 或 `libs/` 构建，全部数据均为合成值；许多交互只是模拟演示，不代表产品已实现。
> 逐屏落点见 [docs/LocalPass-屏对照表.md](../../docs/LocalPass-屏对照表.md)，产品实现基线见 [docs/LocalPass-界面规范.md](../../docs/LocalPass-界面规范.md)。

## 如何打开

1. **直接双击打开**：在 Finder 中双击 `design-system/agy/index.html`（采用传统 `<script src>` 加载，无 `file://` CORS 限制）。
2. **本地静态服务器**：
   ```bash
   cd design-system/agy
   python3 -m http.server 4180
   # 打开 http://localhost:4180
   ```
3. **自检脚本**：
   ```bash
   node design-system/agy/check.js
   ```

## 自检范围与边界

- `check.js` **只验证结构与渲染**：73 个唯一屏 ID、`1 / 29 / 29 / 14` 的界面分布、每屏非空 `id` / `name` / `render`、HTML 标签配平、无 `undefined` / `NaN` / `[object Object]`、无 Emoji，以及 `INITIAL_ITEMS` 中实际出现的全部 8 类条目都能在 Mac 与扩展工作区渲染。
- 它**不验证交互行为**，也不证明产品功能已完成。原型中的许多交互为模拟；自动同步、二维码、文件权限与备份统计等仅为演示或合成占位。
- `tokens.json` 是设计令牌参考快照（W3C DTCG），语义色对齐 `libs/components/src/tw-theme.css`。**产品运行时不消费该文件**；产品样式来源是 `libs/components/src/tw-theme.css` 与 `libs/angular/src/local-ui/agy.scss`。
- 产品仅支持**手动同步**；原型中的“自动同步”开关是概念演示。产品**未实现 HIBP / 泄露查询**，安全体检完全离线。
- 原型生成器的“重新生成”使用 `crypto.getRandomValues`（WebCrypto）；二维码是**确定性合成 SVG 占位矩阵，不可扫描**，产品端使用 `qrious` 在本地生成真实二维码。
