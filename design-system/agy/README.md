## 如何打开

1. **直接双击打开**：在 Finder 中双击 `design-system/agy/index.html`（采用传统 `<script src>` 加载，无 `file://` CORS 限制）。
2. **本地静态服务器**：
   ```bash
   cd design-system/agy
   python3 -m http.server 4180
   # 打开 http://localhost:4180
   ```
3. **自检脚本**：
   ```bash
   node design-system/agy/check.js
   ```
