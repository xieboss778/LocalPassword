## 1. 设计目标与核心改进

本版设计基于项目既有文档（`LocalPass-界面规范.md`、`LocalPass-竞品分析-1Password.md`、`LocalPass-离线优先与R2同步设计.md`）与现有代码（`apps/desktop`、`apps/browser`、`libs/local-vault`、`libs/angular/src/local-ui`），解决三个核心问题：

1. **三端真正联动，而非三套孤立界面**
   - **解锁代理联动（`com.localpass.desktop` Native Messaging）**：Mac 桌面端使用触控 ID / 安全密码解锁后，浏览器扩展与网页内联菜单即时同步为已解锁状态；在浏览器内联浮层中也可直接发起「通过 Mac 触控 ID 解锁」，无需切窗。
   - **写入即见（Save / Update → Vault Ripple）**：网页提交改密后，右上角保存确认条更新条目；扩展详情、Mac 桌面端详情与版本历史（`v3 → v4`）实时同步并标记待同步增量。
   - **剪贴板与撤销闭环**：任意端复制敏感值，统一呈现「行内绿色反馈 + 30 秒倒计时 + 立即清除」；删除条目先软删进回收站并提供 5 秒 Toast 撤销。

2. **极限紧凑但透气（4px 栅格，信息密度提升约 35%–45%）**
   - **Mac 桌面端（`1200×760`）**：`36px` 一体化标题栏 + `196px` macOS Source List 侧栏 + `296px` 列表（`36px` 行高，支持 `30px` 极紧模式）+ 自适应详情主区（`30px` 字段行）+ `188px` 右侧常驻检查器 + `24px` 底部快捷键状态栏。单屏列表可稳定展示 **14–16 条条目**。
   - **浏览器扩展弹窗（`380×600`）**：`38px` 头部 + `28px` 搜索 + `22px` 筛选条 + **当前标签页站点置顶匹配** + `36px` 紧凑列表行 + `38px` 底部 4 标签导航。单屏可稳定展示 **9–10 条条目**，悬停/键盘焦点原地显示「填充」与「复制用户名/密码」，零行宽跳动。
   - **网页内联菜单（`312px` 锚定浮层）**：贴在输入字段下沿 `4px`，`28px` 头部 + `20px` 语境条 + `36px` 账户行 + `26px` 底部操作 + `20px` 键位与隐私说明。支持**登录、通行密钥、验证码（+填充确认胶囊）、银行卡、身份、注册强密码建议、就地解锁（含 Mac 触控 ID 桥接）与保存/更新确认条**。

3. **把代码里已有但缺入口的能力全部接出（消除 P0/P1 摩擦）**
   - **8 类完整条目视图**：`登录`、`令牌`、`SSH 私钥`、`许可证`、`卡片`、`身份`、`服务器`（含跨条目引用 SSH 私钥）、`笔记`，字段严格对齐 `libs/local-vault/src/items/item-fields.ts`。
   - **全字段检索 + 语法过滤**：覆盖名称、用户名、URL、备注、自定义字段、卡号后四位、文件夹，支持 `=favorite` / `=totp` / `=ssh` 等过滤，并在结果行标出「命中来源」。
   - **版本历史与归档**：详情检查器与更多菜单直达版本时间线（字段级 diff、复制旧值、回滚恢复）；归档与回收站明确区分（归档＝收起不删，不进默认搜索）。
   - **多源导入与去重预览**：暴露代码中已注册的 `1Password (.1pux / .1pif / .csv)`、`通用 CSV`、`LocalPass JSON`、`Bitwarden JSON` 与 `Google Authenticator`，预览阶段清晰给出「将导入 / 重复跳过（按 name+user+URI）/ 覆盖 / 无法识别」。
   - **多格式导出**：支持加密 JSON（推荐）、明文 JSON、通用 CSV（含明文警告与安全密码二次校验）。
   - **离线安全体检 + 网络闸门**：本机实时规则检查（重复密码 / 超 365 天未改 / 弱密码 / 缺 2FA），**产品未实现 HIBP 或任何泄露查询，体检完全离线、无出站请求**；网络闸门遵循默认拒绝（Default Deny）与锁库 0 出站原则，仅展示自选白名单规则，绝不包含上游遗留遥测清单。
   - **R2 端到端加密镜像（v2 目标状态）**：把「同步（快照镜像）」与「导出（标准可迁移文件）」拆清；产品**仅支持手动同步**，原型中的“自动同步（30s 去抖/解锁/聚焦）”开关仅是概念演示，产品未实现；同时呈现存储与 CORS 向导、从 `account.json` 桶恢复、已登记设备列表及并排冲突解决（默认保留两份）。
   - **完整 73 屏覆盖**：覆盖对照表全部 **Mac 桌面端 29 屏**（列表不显示动态验证码，仅详情显示 TOTP 动态口令、不内联展示绑定二维码；去掉冗余复制主值按钮；8 类字段各自定制并支持默认/自定义字段动态增删；应用内快捷键可删除，**无系统全局热键，快速检索为应用内 `⌘K`**）、**Chrome 扩展 29 屏**（列表同样去除 2FA 验证码干扰，8 类新建/编辑支持默认与自定义字段增删）及 **网页内联 14 屏**（补齐全新站点无凭据引导、首次保存含文件夹选择、保存成功确认态、弱/重复密码改密提醒条）+ **三端实时联动沙盒**。

## 3. 平台能力与文案红线

1. **生物识别边界**：`触控 ID`（`Touch ID`）仅属于 macOS 桌面端；浏览器扩展原生仅支持 `WebAuthn PRF 安全密钥`，若启用了 `com.localpass.desktop` 原生消息桥接，才可在扩展或网页内联中发起「通过 Mac 桌面端触控 ID 解锁」。
2. **术语红线（对齐 `GLOSSARY.md`）**：
   - 不使用「注册 / 登录 / 账号 / 云服务器」，统一使用「保险库 / 安全密码 / 本机 / 桶 / 同步 / 导出 / 恢复」。
   - 错误与说明文案必须写清后果与可执行出口（如「忘记安全密码只能从恢复包重建」「同步失败不改动本机数据」）。
3. **无障碍与键盘**：
   - 所有交互元素具备 `:focus-visible` 2px 品牌焦点环（在滚动容器内使用 `outline-offset: -2px` 避免被裁剪）。
   - 全程支持 `↑↓` 移动、`↵` 确认/填充、`⌘C` 复制用户名、`⇧⌘C` 复制密码、`⌥⌘C` 复制验证码、`⌘E` 编辑、`⌘K` / `/` 搜索、`esc` 返回/关闭。
   - 全部数字、时间、验证码、倒计时使用 `font-variant-numeric: tabular-nums`。
   - 遵循 `prefers-reduced-motion: reduce`。
   - 不使用 Emoji 作为功能图标，全站统一 `1.5px` 描边几何 SVG 图标。
