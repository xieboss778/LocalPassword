# LocalPass 原型设计 - 竞品分析应用指南

> 本文档将 `docs/LocalPass-竞品分析-1Password.md` 的 11 个具体改进建议（第 8 节）映射到四个 UI 原型的视觉实现，确保每个原型都能演示 LocalPass 相对于 1Password 的核心优势。

---

## 概述

### 竞品分析的三个最优先任务

1. **搜索 + 全局唤起（Quick Search）** — 解决 D1（取用路径）
2. **把已有能力接出来** — 解决 P0-3/P0-4 / P1-4（历史、归档、导出）
3. **键盘与反馈打磨** — 解决 D2、P1-2（键盘密度、复制反馈）

### 四个原型的职责分布

| 原型                       | 形态                   | 主要展示                                     | 关键交互                    |
| -------------------------- | ---------------------- | -------------------------------------------- | --------------------------- |
| **popup-mockup-v2.html**   | 浏览器扩展弹窗 360×600 | Quick Search 提示、搜索范围、复制反馈        | 弹窗内键盘导航、Toast 状态  |
| **android-mockup-v2.html** | Android Material 3     | 搜索升级、键盘提示、entry history            | FAB、搜索范围指示、历史面板 |
| **macos-mockup-v2.html**   | macOS HIG 三列式       | 最完整演示（全局搜索、历史、归档、健康检查） | 键盘驱动流程、详情面板操作  |
| **windows-mockup-v2.html** | macOS HIG light theme  | 微交互、紧凑排版、玻璃态、键盘无鼠标完成     | 基础成熟度展示              |

## 11 个改进建议与原型映射

### 8.1 Quick Search（全局唤起）

**目标**：`Ctrl/Cmd+Shift+Space` 唤起 480×420 无边框搜索窗，输入即出结果，`↑↓` 选择，`Enter` 填充/打开。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 搜索框顶部增加"💡 提示：Ctrl+Shift+Space 唤起全局搜索"
  - 展示快捷键凭据
- **macos-mockup-v2.html**：
  - 新增"Quick Search"菜单项（或快捷键指示）
  - 侧边栏搜索框下增加"`⌘⇧Space` 全局唤起"文案
- **android-mockup-v2.html**：
  - TopAppBar 搜索按钮增加快捷键提示

**UI 变化**：

- 搜索框增加 `aria-label="搜索（Ctrl+Shift+Space 全局唤起）"`
- 新增快捷键速查卡片（可选，桌面端）

---

### 8.2 搜索升级（全字段索引）

**现状**：仅搜 4 个字段（name, subtitle, folder, username）  
**目标**：覆盖备注、URL/URI、自定义字段、卡号后四位；支持引号精确匹配；结果显示"命中位置"。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 搜索框下增加"范围提示"：`🔍 名称 • 用户名 • URL • 备注 • 自定义字段`
  - 搜索结果行下方增加"命中位置"小字（如 `备注：备用码 882…`）
  - 搜索框为空时，显示"📌 最近使用"和"⭐ 收藏"两组
- **android-mockup-v2.html**：
  - 搜索字段下增加标签云（可选）：`全字段搜索支持备注、URL、自定义字段`
  - 结果卡片下显示命中上下文
- **macos-mockup-v2.html**：
  - 侧边栏搜索框下"搜索范围"单行文字
  - 条目列表增加次行"匹配来自：备注 / URL / 字段"

**UI 变化**：

- 搜索容器增加 `<div class="search-hint">搜索覆盖名称、用户名、URL、备注、自定义字段</div>`
- 搜索结果项增加 `.search-match-context` 类显示命中位置

---

### 8.3 键盘体系

**现状**：弹窗内几乎没有全局键位；列表不支持 ↑↓  
**目标**：列表 ↑↓ 移动焦点、`⌘C` 复制用户名、`⇧⌘C` 复制密码、`⌥⌘C` 复制 TOTP、`⌘E` 编辑、`Delete` 归档、`⌘Delete` 删除、`/` 聚焦搜索。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 底部操作栏增加"⌨️ 快捷键"按钮，点击显示快捷键卡片
  - 快捷键卡片内容：
    ```
    列表导航: ↑↓ | Enter 打开
    复制: ⌘C 用户名 | ⇧⌘C 密码 | ⌥⌘C TOTP
    编辑: ⌘E | 删除: Delete | 归档: ⌘⇧A | / 搜索
    ```
  - 列表项增加 `.vault-item:focus-visible` 显示焦点环（蓝色）
  - 演示鼠标无法交互时的键盘流程
- **android-mockup-v2.html**：
  - 条目卡片下增加"快捷键"指示（底部导航栏或菜单）
  - 长按条目显示快捷键浮窗
- **macos-mockup-v2.html**：
  - 条目列表项 hover 时右侧显示快捷键（如 `⌘E` `Delete`）
  - 菜单栏增加"编辑 → 快捷键"（可打开快捷键设置）
  - 演示纯键盘操作：解锁 → 搜索 → 复制 → 编辑 → 保存 → 归档

**UI 变化**：

- 列表项改为 `role="listbox"` 和 `role="option"`，支持 roving tabindex
- 条目名称下增加"快捷键提示"小字（可选）
- 增加快捷键参考卡片组件

### 8.4 条目历史 + 归档

**现状**：组件存在但无 UI 入口  
**目标**：详情页密码行可查看历史并复制旧值；删除改为"归档"；设置页可管理归档条目。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 详情页密码行右侧增加"⋯ 查看历史"链接
  - 点击后弹出"密码历史"面板，显示时间戳、旧值、复制按钮
  - 操作菜单增加"📦 归档"选项
  - 设置页增加"🗂️ 归档"行，显示归档条目计数
- **android-mockup-v2.html**：
  - 详情面板密码字段下增加"📜 查看历史"按钮
  - 底部操作菜单增加"📦 归档此项"
  - BottomSheet 中展示历史版本列表
- **macos-mockup-v2.html**：
  - 详情面板"密码"字段右侧增加"📜 历史"按钮
  - 点击展示"版本时间线"（可视化历史版本）
  - 条目卡片若已归档，显示"[已归档]"标签
  - 侧边栏搜索框下增加"🗂️ 已归档"筛选选项

**UI 变化**：

- 详情操作单增加"📦 归档"按钮
- 新增 `.history-panel` 展示历史版本（时间、值、复制按钮）
- 归档条目在列表中显示 `.archived-badge`

### 8.5 迁移升级（1PUX/CSV 导入 + 去重）

**现状**：仅支持 `.json`；无去重  
**目标**：支持 1PUX、1PIF、CSV；导入预览显示"将导入 / 重复跳过"；按 `name + username + 主 URI` 去重。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 导入页增加四张卡：
    1. LocalPass 备份
    2. Bitwarden 导出
    3. **1Password（.1pux/.1pif/.csv）** ← 新增
    4. 通用 CSV
  - 拖拽区标注"支持 `.1pux` `.1pif` `.csv` `.json`"
  - 预览页显示"将导入 N / 重复跳过 M / 失败 K"统计
- **android-mockup-v2.html**：
  - 导入菜单中突出"1Password 导入"卡片
  - BottomSheet 预览显示导入结果统计
- **macos-mockup-v2.html**：
  - 侧边栏或菜单"文件 → 导入"，显示支持的格式列表
  - 拖拽提示"拖入 1Password 导出文件"

**UI 变化**：

- 导入源卡片增加四个选项
- 文件选择器 `accept` 属性按来源变化
- 预览统计增加"去重"行

### 8.6 导出升级（CSV 暴露）

**现状**：服务支持但未暴露  
**目标**：导出页增加 CSV 和 1PUX；二次验证主密码；风险提示。

**原型展示点**：

  - CSV 选项下增加"⚠️ 警告：包含明文密码"提示
  - 导出前弹出"重新输入主密码"验证
- **macos-mockup-v2.html**：
  - 菜单栏"文件 → 导出"显示三个格式
  - 选择 CSV 时显示风险对话框

**UI 变化**：

- 导出格式列表增加 CSV 单选项
- 增加密码验证弹框
- 增加风险提示文案

### 8.7 保存与更新通知

**现状**：上游通知条，文案未打磨  
**目标**：问句文案"保存到 LocalPass？"，提供"保存 / 更新已有 / 忽略"；成功后 1.5s 内列表可见新条目。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 弹窗顶部增加通知条示例（非交互）：
    ```
    💾 保存到 LocalPass？
    [保存] [更新已有] [忽略]
    ```
  - 通知条下方显示匹配的已有条目（如"已存在 Gmail (user@gmail.com)"）

**UI 变化**：

- 新增 `.save-notification` 组件，显示问句文案 + 三按钮
- 通知条可显示匹配条目摘要

**现状**：内联菜单仅登录、通行密钥、TOTP  
**目标**：检测卡号/有效期/地址时，增加"银行卡 / 身份"分组；支持设置默认项。

**原型展示点**：

- **android-mockup-v2.html**：
  - 条目卡片若含卡号或身份信息，显示"💳 银行卡"或"👤 身份"标签

**UI 变化**：

- 内联菜单分组增加卡和身份类型示例
- 设置页增加"内联菜单 → 默认卡 / 默认身份"选项

**目标**：新增"安全检查"页：本地规则（弱密码、重复使用、超 365 天未改、无 TOTP），可选联网泄露查询。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 设置页增加"🛡️ 安全检查"菜单项
- **android-mockup-v2.html**：
  - 菜单或底部导航增加"安全"标签页
  - 展示问题列表：弱密码、重复使用、超期密码
- **macos-mockup-v2.html**：
  - 侧边栏新增"🛡️ 安全体检"分类项
  - 详情面板展示问题清单与"去修改"按钮

**UI 变化**：

- 新增"Health"页或菜单项
- 显示问题类别与解决链接

### 8.10 反馈闭环（诊断 + 更新日志）

**现状**：无诊断、无日志  
**目标**：关于页新增"生成诊断信息"与"更新日志"；版本、平台、条目计数、错误码（无敏感内容）。

**原型展示点**：

- **popup-mockup-v2.html**：
  - 设置 → 关于页面增加两个按钮：
    - "📋 诊断信息"（点击复制诊断文本到剪贴板）
    - "📄 更新日志"（打开更新历史）
  - 诊断信息示例：
    ```
    LocalPass 诊断报告
    版本：1.0.0 / 平台：Chrome / 条目数：248
    最近错误：0x001 (import-failed) @ 2026-11-27 14:30:42
    ```
- **macos-mockup-v2.html**：
  - 菜单栏"帮助 → 诊断信息 / 更新日志"

**UI 变化**：

- 新增诊断信息生成与复制功能
- 新增更新日志页面

### 8.11 细节改进（11 条）

| #   | 细节         | 现状          | 目标                                   | 原型展示                        |
| --- | ------------ | ------------- | -------------------------------------- | ------------------------------- |
| 1   | Toast 时长   | 固定 1700ms   | 4000ms + 悬停暂停                      | 复制 toast 演示，显示倒计时     |
| 2   | 复制后状态   | 仅 toast      | 字段旁"已复制 · 30s 后清除"            | 详情页复制按钮旁显示状态        |
| 3   | 敏感字段显示 | 手动切换      | 30s 后自动隐藏                         | 密码字段显示/隐藏按钮与定时器   |
| 4   | 删除撤销     | 直接进回收站  | 5s 内提供"撤销"                        | 删除后 toast 显示撤销按钮       |
| 5   | 列表行       | 仅名称/副标题 | 增加"上次使用"相对时间                 | 条目行下显示"上次使用 2 小时前" |
| 6   | 空态         | 已有          | 增加"导入数据 / 新建 / 看快捷键"三入口 | 空库状态显示三个 CTA 按钮       |
| 7   | 图标         | 类型色块      | 本地图标包 + 用户上传                  | 条目图标显示品牌色+首字母       |
| 8   | 焦点         | 部分可见      | 统一 focus ring，键盘操作必见          | 键盘导航时显示蓝色焦点环        |
| 9   | 动效         | 未审计        | 尊重 `prefers-reduced-motion`          | 动画在减速模式下禁用            |
| 10  | 文案         | 对齐原型      | "安全密码" 与 "主密码" 统一            | 确保文案一致性                  |

**原型展示点**：

- **popup-mockup-v2.html**：
  - 展示 toast 倒计时（4s）
  - 详情页复制按钮旁显示"已复制 · 28s 后清除"
  - 密码字段显示/隐藏 + 自动隐藏定时器
  - 删除后提示"撤销"按钮（5s 倒计时）
  - 列表行显示"上次使用 2 小时前"
  - 空库显示"🔄 导入数据 | ➕ 新建 | ⌨️ 快捷键"三按钮
  - 焦点环为蓝色且清晰可见
  - 减速模式下所有动画禁用

- **macos-mockup-v2.html**：
  - 完整演示所有 11 个细节改进
  - 条目列表显示上次使用时间
  - 操作结果 toast 带 4s 倒计时
  - 敏感字段自动隐藏演示

## 视觉层级与主题

### 色彩方案

**Dark Theme（扩展、Android、macOS 侧边栏）**：

- 背景：`#0F1419` / `#1A1F2E`
- 文字：`#F5F7FA` / `#A0AEC0`
- 强调色：`#10B981`（绿色）
- 新增提示/警告：`#F59E0B`（黄色，用于"命中位置"、"去重"等）
- 焦点：`#3B82F6`（蓝色）

**Light Theme（macOS 主体）**：

- 背景：`#FFFFFF` / `#F7F7FB`
- 文字：`#1D1D1D` / `#666666`
- 强调色：`#10B981`

### 排版与间距

- 标题：12–14px，500–600 font-weight
- 正文：12–13px，400 weight
- 副文本：11–12px，400 weight，`#A0AEC0` / `#999999`
- 间距：8px 基础栅格；卡片间距 12px

### 动画

- 入场：`slideInUp` / `slideInDown` 300ms
- 交互反馈：缩放 0.98–1.08，150ms
- Toast：4s 显示 + 1s 淡出，可暂停
- 减速模式：所有动画禁用

## 验收标准

每个原型完成后，应满足：

1. **搜索可用性**：
   - [ ] 搜索框可见"全字段"范围提示
   - [ ] 结果显示"命中位置"
   - [ ] 空搜索显示"最近使用"与"收藏"

2. **键盘无鼠标完成**：
   - [ ] ↑↓ 移动焦点
   - [ ] Enter 打开条目
   - [ ] ⌘C/⇧⌘C/⌥⌘C 复制
   - [ ] ⌘E 编辑、Delete 删除、⌘⇧A 归档

3. **数据安全**：
   - [ ] 历史与归档入口清晰
   - [ ] 删除有撤销选项
   - [ ] 敏感字段自动隐藏

4. **迁移友好**：
   - [ ] 导入支持 1PUX/CSV
   - [ ] 预览显示去重结果
   - [ ] 导出支持 CSV

5. **反馈闭环**：
   - [ ] 操作结果 toast 明确
   - [ ] 诊断信息可生成
   - [ ] 更新日志可查看

6. **可访问性**：
   - [ ] 焦点环始终可见
   - [ ] 所有按钮有 ARIA 标签
   - [ ] 色彩对比度 ≥ 4.5:1
   - [ ] 减速模式下无强制动画
