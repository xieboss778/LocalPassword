# 方向 C「分组原生」完整原型

拍板结果：**C 分组原生**。这里是它的完整产品界面（不是四个界面的草图）。

- 扩展弹窗 **380 × 620**：26 个界面
- 桌面端 **1160 × 760**：10 个界面（侧栏 + 列表 + 详情三栏，含完整增删改查）

打开：双击 `index.html`（零依赖，不需要构建）。左侧目录选界面，界面里的行可点，`↑` `↓` 也能翻；左侧末尾有**五条关键流程**，点了会跳到该流程的起点。

规范（令牌、组件规则、平台能力矩阵、文案规则、落码顺序）见 [docs/LocalPass-界面规范.md](../../docs/LocalPass-%E7%95%8C%E9%9D%A2%E8%A7%84%E8%8C%83.md)。

## 覆盖的流程

| 分组 | 界面 |
| --- | --- |
| 首次使用 | 设置安全密码（邮箱仅作本机派生密钥 / 从备份恢复入口）；生物识别不在向导里 |
| 解锁 | 只输安全密码（扩展无生物识别接口）；输错 5 次进入等待且**不登出、不删数据** |
| 保险库 | 有数据（收藏 / 全部）、空状态（引导新建或导入）、页面内联填充菜单 |
| 条目 | 详情（凭据/自动填充/Passkey/自定义字段/附加项）、编辑（登录 / 卡片，字段对齐上游 cipher-form）、Passkey、动态口令二维码 |
| 工具 | 生成器（密码 / 短语）、Google 认证器导入、导入预览、安全密钥（PRF） |
| 备份（手动） | 云备份面板、存储配置、从备份恢复 |
| 回收站 | 删除（底部操作单：克隆/收藏/移到回收站）、回收站（恢复 / 永久删除 / 清空） |
| 状态与异常 | 恢复中、同步冲突（三选一）、连接失败（403） |
| 设置 / 系统 | 设置一级、网络闸门（拦截清单）、数据与安全（导出/导入/销毁） |
| 桌面端 | 设置密码、解锁（含 macOS Touch ID）、**详情（读 · 全字段）**、**新建（增 · 完整表单）**、**编辑（改 · 完整表单）**、**删除确认（删）**、**回收站**、生成器、安全设置、备份设置 |

## 设计约定（写进实现时的规矩）

1. **没有账号语义**：全程不出现「注册 / 登录 / 账号」。邮箱只出现在首次设置里，标注为「仅本机派生密钥」。
2. **没有后台任务**：备份页明确写「只在你点的时候联网」；桌面端写「收进托盘也不会自动上传」。
3. **分组列表是唯一容器**：所有列表 = `分组标题 + 圆角卡片 + 行`；行右端只有三种收尾：值 / 开关 / chevron。
4. **危险操作下沉**：断开存储、移除密钥、清空保险库统一放页尾，红色描边，不用实心红。
5. **状态一律用行内提示**，不用全局横幅：网络闸门、冲突、等待锁定都贴在使用处。
6. 颜色：底 #f2f3f6、卡片 #fff、主色 #2f6bff、成功 #34c759、危险 #d2483c；圆角 12；阴影只用 1px + 极淡。
7. **Touch ID 只在 macOS 桌面端存在**，且入口只出现在「设置 → 安全」；首次向导与扩展弹窗里都不出现。
