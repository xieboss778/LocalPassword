# LocalPass Send

This folder contains 2 packages that can be used to create and modify Sends.

## semd-core

Package name: `@localpass/send-core`

Contains all types, models, and services for LocalPass Send

Currently in use by the LocalPass Web Vault, CLI, desktop app and browser extension

## send-ui

Package name: `@localpass/send-ui`

Contains all UI components used for LocalPass Send
